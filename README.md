# Hospital Readmission Analysis – Excel

## Project Overview

This project analyzes hospital admission data to identify patterns and factors associated with hospital readmissions. The analysis focuses on data quality, patient characteristics, clinical information, and readmission patterns.

## Objective

- Assess the quality and completeness of the hospital dataset
- Analyze patient and admission characteristics
- Identify patterns associated with readmissions
- Examine potential risk factors
- Generate business and healthcare insights

## Data Analysis

- Data cleaning and preparation
- Missing and unknown value analysis
- Data quality assessment
- PivotTable analysis
- Readmission analysis
- Risk analysis
- Dashboard development

## Tools

- Microsoft Excel
- Excel Formulas
- PivotTables
- Charts
- Dashboard

## Workbook Structure

- Raw Data
- Cleaned Data
- Data Quality
- Pivot Tables
- Dashboard

## Files

- `.xlsx` – Complete Excel analysis workbook
- Dataset – Source data used for analysis

## Conclusion

The project demonstrates the use of Excel for data cleaning, data quality assessment, exploratory analysis, visualization, and dashboard creation to understand hospital readmission patterns.
