# Hospital Readmission Analysis – Excel

## Project Overview

This project analyzes hospital admission data using Microsoft Excel to identify patterns and factors associated with hospital readmissions. The analysis focuses on data quality, patient characteristics, clinical information, and readmission patterns.

## Objective

The objective of this project is to assess hospital admission data, identify data quality issues, analyze readmission patterns, examine potential risk factors, and generate meaningful healthcare insights using Excel.

## Dataset

The dataset contains hospital admission and patient-related information, including demographic characteristics, medical specialties, diagnoses, admission details, and readmission-related information.

## Data Quality Analysis

A data quality assessment was performed to identify missing and unknown values across important fields, including:

- Weight
- Medical Specialty
- Race
- Primary Diagnosis
- Secondary Diagnoses
- Additional Diagnosis Information

Missing-value percentages were calculated to understand the completeness of the dataset.
